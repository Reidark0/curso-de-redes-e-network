Exemplo empresarial

Uma empresa pode usar: VLAN 10 para usuários administrativos, VLAN 20 para servidores internos, VLAN 30 para telefonia IP, VLAN 40 para convidados, VLAN 50 para câmeras e VLAN 99 para gerenciamento de rede.

Com isso, o broadcast fica restrito a cada grupo e o firewall aplica a política: convidados não acessam servidores; câmeras só enviam vídeo para o gravador; usuários acessam apenas os sistemas de que precisam; o gerenciamento só é aceito a partir de estações administrativas.
