Conceito

Definição: protocolo é o contrato de comunicação entre sistemas. Ele diz o que pode ser enviado, em que formato, em que ordem, em qual momento, com qual resposta esperada e como lidar com exceções.

A definição vale para qualquer protocolo, de rede ou de aplicação. TCP tem regras para estabelecer conexão, numerar bytes, confirmar recebimento e encerrar sessão. HTTP tem regras para método, URL, headers, status code e corpo. DNS tem regras para pergunta, tipo de registro e resposta. TLS tem regras para handshake, certificados, chaves e algoritmos. OIDC tem regras para autenticação federada, redirecionamento, tokens e validação.
