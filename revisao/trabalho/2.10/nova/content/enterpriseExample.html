Exemplo empresarial

Um usuário não acessa um sistema interno. Cada time fala a sua língua: rede valida VLAN, IP, rota, firewall e porta; segurança valida política, VPN, proxy, logs e segmentação; identidade valida grupo, MFA e token; aplicação valida status HTTP, logs de backend e autorização. O OSI é o vocabulário comum que aponta todos para o mesmo fluxo.

Com ele, ninguém culpa ninguém sem prova. Se há TCP estabelecido e HTTP 403, a hipótese de bloqueio de firewall perde força. Se não há ARP para o gateway, não faz sentido investigar token. Se o DNS resolve para um IP público errado, não adianta reiniciar a aplicação.
