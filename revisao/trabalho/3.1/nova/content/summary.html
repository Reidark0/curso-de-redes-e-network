Resumo

  • Ideia central: Ethernet é o envelope local da LAN cabeada: entrega frames entre interfaces próximas usando MACs e switches; o IP cuida do endereçamento entre redes.
  • Como funciona: o host põe o pacote IP num frame; o switch aprende MACs por porta e encaminha, ou faz flooding se não conhece o destino.
  • Erro comum: confundir Ethernet com internet, IP ou Wi-Fi e culpar o DNS antes de checar link e gateway.
  • Diagnóstico: Camada 1 (link, velocidade, duplex, CRC) → Camada 2 (MAC, VLAN, ARP) → Camada 3 (IP, gateway).
  • Segurança: MAC não é identidade forte; portas, VLANs, NAC/802.1X, inventário e monitoramento são a base.
