Conceito

Definição: Ethernet (IEEE 802.3) é uma família de tecnologias de LAN que permite a troca de quadros (frames) entre interfaces de rede usando endereços MAC. Ela define a parte física e a de enlace: meios, velocidades, endereçamento MAC, formato do frame e regras da comunicação local.

Seu computador cabeado não põe “um pacote IP puro” no cabo: ele encapsula o pacote IP num frame Ethernet com MAC de origem, MAC de destino e outros campos, e o switch lê o frame para decidir a porta de saída. O frame vale só até o próximo equipamento de camada 3. O roteador descarta o frame e monta outro, com novos MACs, para o trecho seguinte; os IPs do pacote continuam os mesmos (exceto se houver NAT).

Ethernet não é Wi-Fi, IP, TCP nem internet

Erros comuns:
  • Confundir Ethernet com internet: leva a tratar um problema local como falha do provedor.
  • Usar o MAC como identidade: ele pode ser alterado em software; correlacione com NAC, autenticação, inventário e logs.
  • Trocar o cabo de porta sem olhar a VLAN: a porta parece igual, mas o host cai em outro segmento. Confira o switchport (access/trunk) e a documentação.
  • Culpar o DNS primeiro: siga a ordem link → IP local → gateway → DNS → transporte → aplicação.
