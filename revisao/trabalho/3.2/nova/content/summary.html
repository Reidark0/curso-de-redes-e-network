Resumo

  • Ideia central: o frame é o envelope local da LAN. O MAC leva o frame até a próxima interface do enlace; o IP leva o pacote até o destino final. A cada salto roteado, os MACs mudam e os IPs permanecem.
  • Campos: MAC de destino (6 bytes), MAC de origem (6), EtherType (2), payload (46–1500) e FCS (4); a tag 802.1Q opcional soma 4.
  • Tipo de destino: ff:ff:ff:ff:ff:ff é broadcast; bit I/G = 1 no primeiro byte indica multicast; 0 indica unicast.
  • Fora da sub-rede: o MAC de destino é o do gateway, não o do servidor final.
  • Segurança: MAC é evidência de interface, não identidade forte; correlacione com porta, VLAN, DHCP, NAC, inventário e logs.
