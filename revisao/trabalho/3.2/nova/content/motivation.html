Motivação

Você abre uma captura no Wireshark e vê a linha Ethernet II, Src: 3c:52:82:aa:10:22, Dst: ff:ff:ff:ff:ff:ff. Para quem entende Camada 2, ela já conta uma história: qual interface enviou, para quem a entrega local se destina (aqui, todos os hosts do segmento, porque é um broadcast) e, no campo seguinte, qual protocolo vai dentro.

O frame Ethernet é a unidade de entrega local, e o endereço MAC é o identificador de interface usado nessa entrega. Switch, tabela MAC, ARP, VLAN, flooding e port security, os temas das próximas aulas, dependem de você saber ler esses dois elementos.

Problema real: um SOC observa tráfego estranho vindo de um MAC desconhecido, mas o IP muda ao longo do dia. Quem só olha IP perde a pista. Quem sabe interpretar MAC, OUI, porta de switch, VLAN e frame consegue relacionar evidências de rede, inventário e segurança física.
