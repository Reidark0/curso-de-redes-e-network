Funcionamento interno

No pacote não existem pontos. No cabeçalho IPv4, os campos Source Address e Destination Address têm 32 bits cada. O sistema converte o decimal pontuado para bits sempre que precisa aplicar máscara, comparar rede e host ou calcular rotas:

  1. O host lê o endereço configurado em decimal pontuado, por exemplo 192.168.10.25 (falha típica: endereço inválido ou duplicado).
  2. Cada octeto é validado: precisa haver exatamente quatro, todos entre 0 e 255.
  3. Cada octeto é convertido para 8 bits, e os quatro juntos formam o endereço de 32 bits.
  4. A máscara/CIDR é aplicada sobre esses bits para separar a parte de rede da parte de host (falha típica: máscara incorreta coloca o host em outra rede).
  5. A tabela de rotas usa o resultado bit a bit para decidir se o destino é local ou se vai para o gateway (falha típica: gateway fora da rede local ou rota ausente).

Como converter um octeto

Cada um dos 8 bits tem um peso fixo, do mais significativo (esquerda) ao menos significativo (direita). O valor decimal é a soma dos pesos dos bits ligados.

  • Decimal → binário: percorra os pesos da esquerda para a direita. Se o peso cabe no que sobrou, escreva 1 e subtraia; se não cabe, escreva 0. Para 168: 128 cabe (sobra 40), 64 não, 32 cabe (sobra 8), 16 não, 8 cabe (sobra 0), o resto é 0 → 10101000.
  • Binário → decimal: some os pesos dos bits 1. 00011001 = 16 + 8 + 1 = 25.
  • Por que 255 é o máximo: com os 8 bits ligados, a soma é 255. O valor 256 já precisaria de um nono bit.
Erros comuns:
  • Remover os zeros à esquerda: 10 em binário é 1010, mas como octeto é 00001010. Cada octeto tem sempre 8 bits; sem os zeros, os cálculos de máscara e subnetting saem errados.
  • Aceitar octeto acima de 255 ou achar que todo número com pontos é IPv4 (parece número de versão de software): confirme quatro octetos, cada um entre 0 e 255, e só então valide máscara, rota e contexto.
  • Achar que os três primeiros octetos são sempre a rede: isso só vale para /24, comum em casa. Com /16, /20 ou /27, a divisão muda e pode cair no meio de um octeto.
  • Ler os octetos como quatro números independentes: eles formam uma única sequência de 32 bits, e é sobre ela que o sistema aplica a máscara.
