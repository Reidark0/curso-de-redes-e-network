Exemplo em DevSecOps

Em pipelines, as camadas superiores aparecem quando um runner acessa registry, API de cloud, Vault, GitHub, Kubernetes API Server ou um endpoint interno. O TCP pode abrir e o job falhar por certificado não confiável, proxy corporativo, token expirado, escopo insuficiente, JSON inválido, erro 429 de rate limit ou política de admission controller.

Pipelines maduros validam certificados, registram as respostas HTTP, não imprimem tokens, usam secrets corretamente e distinguem erro de rede de erro de autenticação.
