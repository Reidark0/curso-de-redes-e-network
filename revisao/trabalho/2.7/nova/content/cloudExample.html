Exemplo em cloud

Em cloud, um acesso a API pode passar por DNS gerenciado, CDN, WAF, load balancer, API gateway, serviço de identidade, service mesh e backend em container. A VPC/VNet, as subnets e os security groups podem estar corretos, e a API falhar por certificado errado, domínio fora do SAN, rota de API ausente, authorizer mal configurado, token sem claim ou payload maior que o limite do gateway.

Essas camadas também custam: logs de WAF, API gateway e load balancer, certificados gerenciados e observabilidade geram cobrança recorrente de armazenamento e retenção.
