Exemplo simples

Seu notebook está conectado ao Wi‑Fi, mas nenhum site abre. Uma sequência básica:

  1. Rode ipconfig /all para ver se recebeu IP válido, gateway e DNS.
  2. Rode ping <gateway> para testar alcance até o roteador local.
  3. Rode arp -a para verificar se o gateway tem endereço MAC conhecido.
  4. Rode ping 8.8.8.8 ou outro destino autorizado para testar saída por IP.
  5. Rode nslookup exemplo.com para testar resolução de nomes.
  6. Se IP funciona e nome não, a hipótese de DNS ganha força.
