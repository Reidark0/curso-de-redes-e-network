Exemplo empresarial

Um usuário não acessa o ERP interno. O suporte coleta ipconfig /all e percebe que o notebook está na VLAN de visitantes. O ping para o gateway responde, mas o tracert para o ERP para no firewall. O nslookup resolve o nome para o IP interno correto. A evidência indica que o problema não é DNS nem link físico: é segmentação ou política entre VLANs.

Em vez de “o sistema caiu”, o chamado pode dizer: “host na rede de visitantes resolve o nome do ERP, alcança o gateway, mas o tráfego até a rede do ERP é interrompido no firewall”. Assim o time certo é acionado.
