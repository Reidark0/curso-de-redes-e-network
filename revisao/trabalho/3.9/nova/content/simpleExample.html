Exemplo simples

Um host Linux na VLAN 10 perde acesso intermitente aos sistemas internos. O cache ARP (valores fictícios) mostra:

$ ip neigh
192.168.10.1  dev eth0 lladdr aa:bb:cc:11:22:33 REACHABLE
192.168.10.57 dev eth0 lladdr aa:bb:cc:11:22:33 STALE

O gateway (192.168.10.1) e a estação 192.168.10.57 aparecem com o mesmo MAC, e o inventário registra outro MAC para o gateway. No switch, você procura onde esse MAC está:

switch# show mac address-table address aabb.cc11.2233
Vlan    Mac Address       Type        Ports
----    -----------       --------    -----
  10    aabb.cc11.2233    DYNAMIC     Gi1/0/12

Interpretação: o MAC que responde pelo gateway está numa porta de usuário (Gi1/0/12), não no uplink do gateway. Antes de concluir ARP spoofing, descarte a explicação legítima: um gateway com HSRP/VRRP usa MAC virtual (0000.0c07.acXX no HSRP, 0000.5e00.01XX no VRRP), aprendido no uplink, não numa porta de acesso. Aqui a evidência aponta para associação ARP indevida; o controle que faltou é DAI com DHCP snooping.
