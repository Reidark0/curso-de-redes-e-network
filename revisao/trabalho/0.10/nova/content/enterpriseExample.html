Exemplo empresarial

Um usuário reclama que o sistema financeiro está lento. A revisão orienta perguntas em ordem, de baixo para cima: o sinal físico está estável? O problema ocorre no cabo e no Wi-Fi? A latência até o gateway está normal? A resolução de nome responde? A porta está acessível? O protocolo retorna erro? O problema está no login? Há proxy ou inspeção TLS? Existem logs de bloqueio?

Esse raciocínio evita que o time compre mais banda quando o problema é DNS, troque o firewall quando o problema é a aplicação ou culpe a autenticação quando o problema é conectividade básica.
