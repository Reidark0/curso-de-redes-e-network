Conceito

Definição: IPv4 é o protocolo de Camada 3 que identifica hosts e redes de forma lógica, para que roteadores encaminhem pacotes entre redes diferentes.

Um endereço IPv4 tem 32 bits, normalmente escritos em quatro octetos decimais, como 192.168.10.20. Ele não substitui Ethernet: trabalha acima dela. Ethernet entrega o frame ao próximo salto local; IPv4 identifica a origem e o destino lógicos do pacote.

O IPv4, sozinho, não garante entrega, confidencialidade, autenticação nem autorização. E um IP identifica um ponto lógico da rede em determinado momento, não necessariamente uma pessoa ou um processo.

Erros comuns:
  • Confundir IP com MAC. Os dois aparecem como identificadores, e aí você tenta resolver roteamento olhando só tabela MAC ou ARP. MAC é entrega local (Camada 2); IPv4 é endereço lógico roteável (Camada 3).
  • Achar que DNS é necessário para pingar um IP. DNS só traduz nome em IP; tráfego para um IP direto não depende de DNS. Se o ping por IP falha, o problema está em IP, rota, gateway ou bloqueio.
  • Usar IP como identidade de usuário. Com NAT, DHCP ou proxy, a investigação pode atribuir a ação à pessoa errada. Correlacione o IP com DHCP, autenticação, proxy, EDR, VPN e horário.
