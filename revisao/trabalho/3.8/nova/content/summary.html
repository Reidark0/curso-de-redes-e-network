Resumo

  • Ideia central: o STP é o freio da redundância Ethernet: mantém os cabos extras, mas só deixa encaminhar caminhos sem ciclos.
  • Por que existe: o frame Ethernet não tem TTL; num loop surgem broadcast storm e MAC flapping.
  • Como decide: menor Bridge ID é a raiz; cada switch tem uma root port (menor custo); cada link, uma designated; o resto fica alternate.
  • Erro comum: achar que dois cabos somam velocidade ou que porta bloqueada é defeito.
  • Defesa: root planejada, PortFast + BPDU Guard no acesso, Root Guard na distribuição, storm control e alertas de mudança de root e MAC flapping.
