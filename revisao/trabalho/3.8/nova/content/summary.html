Resumo

  • Ideia central: o STP é o freio de segurança da redundância Ethernet: não remove os cabos extras, só decide quais caminhos encaminham sem formar ciclos.
  • Por que existe: o frame Ethernet não tem TTL; num loop, broadcasts se multiplicam (broadcast storm) e a tabela MAC oscila (MAC flapping).
  • Como decide: menor Bridge ID vira root bridge; cada switch escolhe a root port (menor custo até a raiz); cada link tem uma designated port; as demais ficam alternate/bloqueadas.
  • Erro comum: achar que dois cabos aumentam a velocidade ou que porta bloqueada é defeito.
  • Defesa: root primária/secundária planejada, PortFast + BPDU Guard em portas de usuário, Root Guard na distribuição, storm control e monitoramento de mudança de root e MAC flapping.
