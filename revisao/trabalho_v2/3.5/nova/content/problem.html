Problema

É isso que acontece quando um host sabe para qual IP quer falar, mas não sabe qual MAC colocar no frame. IP e MAC têm escopos diferentes: o IP é o endereço lógico de Camada 3, usado para decidir entre redes; o MAC é o endereço de Camada 2 que entrega frames dentro do enlace local. Um pacote IP não atravessa a Ethernet sozinho: ele viaja dentro de um frame com MAC de origem e de destino.

Manter à mão uma tabela IP-MAC em cada host não funciona: placas são trocadas, impressoras entram, notebooks mudam de rede. O ARP (Address Resolution Protocol) automatiza essa ligação: pergunta em broadcast quem tem aquele IPv4 e guarda a resposta por algum tempo. A simplicidade tem um preço: o ARP aceita respostas sem autenticação.
