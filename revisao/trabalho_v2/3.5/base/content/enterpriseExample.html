Exemplo empresarial

Numa filial, os usuários recebem IP via DHCP mas não acessam os sistemas internos, e o chamado chega como "problema de DNS ou de firewall". O analista confere IP, máscara e gateway e depois roda arp -a: o gateway não aparece. A investigação passa para a Camada 2: VLAN, trunk, porta, gateway desligado, firewall local ou bloqueio.

Em outro cenário, o MAC do gateway muda várias vezes durante o dia. Isso pode ser failover legítimo, IP duplicado, MAC flapping ou comportamento suspeito, e só a correlação com o switch e a documentação diz qual.
