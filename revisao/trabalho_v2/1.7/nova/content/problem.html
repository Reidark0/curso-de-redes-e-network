Problema

É isso que acontece quando todos os equipamentos são tratados como “a caixa que passa internet”. Uma rede precisa cumprir várias tarefas: ligar cada dispositivo ao meio, entregar dados entre máquinas da mesma rede local, levar dados de uma rede para outra, aceitar clientes sem fio e decidir o que pode passar. Cada equipamento se especializou numa dessas tarefas. As primeiras redes locais usavam hubs, que só repetiam o sinal; o switch surgiu para entregar cada dado apenas ao destino.

A confusão piora porque o roteador de casa junta quase tudo numa caixa só. Esta aula separa os papéis: que informação cada equipamento lê, que tabela ou regra consulta e que decisão toma. Com isso, você sabe por onde começar a investigar.
