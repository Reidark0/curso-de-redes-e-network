Resumo

  • Ideia central: decimal, binário e hexadecimal são três escritas dos mesmos bits: 192 = 11000000 = C0.
  • 1 byte (octeto) = 8 bits; 1 dígito hexadecimal = 4 bits; 2 dígitos = 1 byte.
  • n bits guardam 2n valores: 8 bits vão de 0 a 255; 16 bits, de 0 a 65535.
  • Pesos do octeto: 128, 64, 32, 16, 8, 4, 2, 1. Mantenha os zeros à esquerda: 10 = 00001010 = 0A.
  • Hexadecimal é só uma escrita compacta; não é criptografia.
