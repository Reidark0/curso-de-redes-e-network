Problema

Esses números parecem de mundos diferentes porque máquina e pessoa precisam de escritas diferentes para os mesmos bits. O circuito trabalha em base 2, com dois estados, como você viu na aula 0.1. Só que binário fica longo demais para humanos: um endereço físico de 48 bits escrito em binário tem 48 caracteres, difíceis de ler, copiar e comparar. O decimal, que usamos no dia a dia, é curto, mas esconde onde está cada bit.

A solução adotada foi o hexadecimal (base 16), em que cada dígito corresponde a exatamente 4 bits. Por isso as ferramentas alternam entre as três bases, e você precisa ler qualquer uma delas e passar de uma para outra. Esta aula mostra como cada base funciona e como converter à mão.
