Arquitetura

Bits, bytes e bases aparecem em todas as camadas. Conhecer o tamanho de cada campo explica os limites que você encontra: um octeto IPv4 vai de 0 a 255, uma porta vai de 0 a 65535, o MAC tem 6 bytes e o IPv6 é muito maior que o IPv4.

Camada Campo Tamanho Como costuma ser exibido
Física Bits em trânsito — Sinais elétricos, ópticos ou de rádio
Enlace Endereço MAC 48 bits (6 bytes) Seis pares hexadecimais: 3c:52:82:1a:2b:3c (Linux), 3C-52-82-1A-2B-3C (Windows), 3c52.821a.2b3c (Cisco)
Enlace EtherType 16 bits Hexadecimal: 0x0800 (IPv4), 0x86DD (IPv6)
Rede Endereço IPv4 e máscara 32 bits (4 octetos) Decimal pontuado (192.168.10.50, 255.255.255.0) ou prefixo (/24)
Rede Endereço IPv6 128 bits Grupos hexadecimais (fe80::1)
Transporte Porta TCP/UDP 16 bits Decimal (443)
Transporte Flags TCP 1 bit cada Nome da flag ou valor hexadecimal no dump
Aplicação Payload Sequência de bytes Texto, JSON, Base64, binário, compactado ou criptografado; em dumps, hexadecimal

Repare que o mesmo MAC aparece com separadores diferentes conforme a ferramenta. Os bytes são os mesmos; só muda a forma de exibir.

Ponto de segurança: uma ferramenta quase sempre mostra uma interpretação dos bytes. Antes de concluir algo, distinga valor bruto, representação visual, codificação, compressão, serialização e criptografia.
