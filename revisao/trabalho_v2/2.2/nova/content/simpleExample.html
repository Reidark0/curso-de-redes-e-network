Exemplo simples

No mesmo notebook, você roda nslookup example.com 8.8.8.8 com o Wireshark capturando. Ao clicar no pacote da consulta, o Wireshark mostra o desencapsulamento de fora para dentro, uma linha por camada (resumido):

Frame 1: 71 bytes on wire
Ethernet II, Src: (MAC do notebook), Dst: (MAC do gateway 192.168.1.1)
Internet Protocol Version 4, Src: 192.168.1.20, Dst: 8.8.8.8
User Datagram Protocol, Src Port: 53124, Dst Port: 53
Domain Name System (query)

Leia cada linha como uma PDU: Frame é o que a placa capturou; Ethernet II é o quadro, com destino no gateway, e não no 8.8.8.8, porque o servidor está fora da sua rede; Internet Protocol Version 4 é o pacote, com o destino final; User Datagram Protocol é o datagrama, que aponta a porta 53 do DNS; e Domain Name System são os dados.

Some os bytes: 14 do cabeçalho Ethernet + 20 do IPv4 + 8 do UDP + 29 da consulta = 71 (a captura normalmente não mostra os 4 bytes do FCS). Numa mensagem pequena como essa, 42 dos 71 bytes são envelope.
