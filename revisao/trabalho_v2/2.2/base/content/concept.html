Conceito

Encapsulamento é o processo no qual os dados de uma camada superior recebem informações adicionais para serem tratados pela camada inferior: quase sempre um cabeçalho, na frente, e às vezes um trailer, no fim. Na Ethernet, o trailer é o FCS (Frame Check Sequence), de 4 bytes, que permite detectar quadros corrompidos. Desencapsulamento é o inverso: o destino valida, interpreta e remove essas informações camada por camada até entregar os dados à aplicação.

Definição: PDU (Protocol Data Unit) é a unidade de dados tratada por uma camada específica. O nome varia conforme a literatura; o uso mais comum é segmento para TCP e datagrama para UDP.

Erros comuns:
  • Chamar toda PDU de pacote. O diagnóstico passa a misturar quadro, pacote e segmento. Use “pacote” para a camada de rede e “PDU” como termo genérico.
  • Achar que o MAC de destino é o do servidor final. O IP é fim a fim; o MAC é do próximo salto. Fora da LAN, é normalmente o MAC do gateway local.
  • Confundir encapsulamento com criptografia. Encapsular acrescenta contexto; cifrar esconde conteúdo.
