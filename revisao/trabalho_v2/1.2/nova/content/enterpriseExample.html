Exemplo empresarial

Uma estação de trabalho acessa um sistema interno. A estação é dispositivo final. O switch de acesso conecta a estação à LAN. Um roteador ou switch de camada 3 encaminha para outra VLAN. Um firewall aplica política entre os segmentos. O DNS interno traduz o nome. O balanceador distribui para os servidores. O serviço web conversa com o banco de dados e com o diretório de identidade.

No inventário de segurança, todos esses elementos importam: a estação pode ter malware; o switch pode ter uma porta indevida; o firewall, uma regra ampla; o servidor, um serviço desnecessário exposto; o DNS pode apontar para um IP antigo; e o balanceador pode mascarar o IP de origem se os logs não forem configurados corretamente.
