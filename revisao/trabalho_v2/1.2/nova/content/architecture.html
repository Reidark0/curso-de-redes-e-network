Arquitetura

Numa arquitetura real os papéis aparecem juntos. Use esta tabela como checklist ao desenhar um fluxo e anotar o papel de cada componente.

PapelFunção principalExemplosO que observar
Dispositivo finalOrigem ou destinoNotebook, celular, servidor, VM, container, impressora, câmeraIP, MAC, interface, sistema, agente, credenciais, portas locais
IntermediárioEncaminhar, comutar, filtrar, traduzir ou inspecionarSwitch, roteador, firewall, AP, proxy, NAT, load balancer, gatewayTabelas, rotas, VLANs, regras, logs, estado da interface
ServiçoEntregar uma função acessívelDNS, DHCP, HTTP, SSH, SMB, RDP, Active Directory, API, banco, registry de containersNome, IP, porta, protocolo, processo, autenticação, autorização
PolíticaDecidir o que é permitidoACL, regra de firewall, security group, RBAC, política de proxyOrigem, destino, porta, identidade, horário, logs e exceções

Essa visão volta em todo o curso: Ethernet aprofunda os switches, IP os roteadores, TCP/UDP os serviços e portas, firewall a política, e cloud mostra versões virtuais desses mesmos papéis.
