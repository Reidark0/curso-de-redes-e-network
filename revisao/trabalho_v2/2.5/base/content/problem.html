Problema

Se todos os dispositivos do mundo dependessem só de MAC e broadcast, a rede global seria inviável: excesso de broadcast, nenhuma hierarquia, nenhuma sumarização e pouco controle. O MAC identifica uma interface dentro de um enlace; ele não diz onde o host está. O IP nasceu, como parte da arquitetura da internet, para resolver isso: ele indica a posição do host numa estrutura lógica de redes e sub-redes, o que permite conectar LANs, WANs, datacenters, provedores e nuvens.

  • Endereçamento lógico: identificar redes e hosts de forma hierárquica.
  • Decisão de caminho: escolher para onde enviar pacotes destinados a outras redes.
  • Controle de loops: o TTL impede que um pacote circule para sempre.

Com a Camada 3 mal configurada, o host acessa a LAN mas não sai dela, duas sub-redes não se comunicam ou a VPN conecta mas não alcança os sistemas.
