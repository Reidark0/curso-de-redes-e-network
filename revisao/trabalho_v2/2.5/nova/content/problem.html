Problema

Sair da rede local é justamente o que a Camada 2 não faz. Na aula 2.4 você viu que ela entrega quadros pelo MAC dentro da rede local. Mas o MAC identifica uma interface; ele não diz onde ela está. Se a internet inteira dependesse de MAC e broadcast, cada equipamento teria de conhecer todos os outros, e o broadcast inundaria tudo. O IP, criado com a própria internet para interligar redes diferentes, resolve isso com um endereço hierárquico: uma parte indica a rede, a outra indica o host. Com ele, a Camada 3 cuida de três coisas:

  • Endereçamento lógico: identificar redes e hosts de forma hierárquica.
  • Decisão de caminho: escolher para onde enviar o que vai para outra rede.
  • Controle de loops: o TTL impede que um pacote circule para sempre.
