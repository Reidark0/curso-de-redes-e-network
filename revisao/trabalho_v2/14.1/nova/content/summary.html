Resumo

  • Ideia central: a cloud não elimina a rede; transforma switches, cabos e firewalls em objetos criados por API e cobrados por uso.
  • O provedor opera o hardware; endereços, rotas, regras e logs são seus.
  • VPC (AWS), VNet (Azure) e VPC Network (Google Cloud) são a mesma rede virtual isolada.
  • Recurso privado sai pelo NAT; a entrada pública passa pelo load balancer.
  • Criar rápido também é errar rápido: IP público, regra aberta, logs desligados.
