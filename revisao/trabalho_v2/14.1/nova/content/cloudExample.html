Exemplo em cloud

Uma loja virtual pequena vai para a AWS. A rede fica assim:

  • VPC 10.40.0.0/16.
  • Subnet pública 10.40.1.0/24: só o load balancer, com endereço público, recebendo HTTPS (porta 443).
  • Subnet privada 10.40.2.0/24: a aplicação, sem IP público; o security group aceita a porta 443 só vindo do load balancer.
  • Subnet privada 10.40.3.0/24: o banco PostgreSQL gerenciado pelo provedor, sem IP público, aceitando a porta 5432 só vindo da aplicação.
  • Saída e registros: a aplicação sai para a internet pelo NAT Gateway; flow logs ligados desde o primeiro dia.

Em Azure ou Google Cloud, o desenho seria o mesmo; mudariam os nomes:

Entender o papel de cada objeto vale nos três provedores; decorar só os nomes, não.
