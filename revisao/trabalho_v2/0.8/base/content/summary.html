Resumo

  • Ideia central: não trate "rede" como caixa preta. Transforme cada sintoma em perguntas por responsabilidade: meio, enlace, endereço, rota, porta, protocolo, aplicação, identidade, política e evidência.
  • Como funciona: cada camada encapsula os dados da camada de cima; as camadas se influenciam, e modelos como OSI e TCP/IP são mapas, não a realidade completa.
  • O que lembrar: conectividade, protocolo, identidade, autorização e aplicação são coisas diferentes (ping respondendo não prova que o HTTPS funciona; 401 não é o mesmo que 403).
  • Erro comum: usar o teste de uma camada para concluir sobre todas as outras.
  • Uso real: troubleshooting, cloud, DevSecOps, IAM, SOC, arquitetura e resposta a incidentes.
