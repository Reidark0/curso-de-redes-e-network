Motivação

Você já deve ter ouvido, ou dito, que “a internet caiu” quando só um site não abria. No trabalho, a versão disso é o chamado “o sistema não funciona”. Imagine um caso: o ping para o servidor responde, mas o login falha. Um analista conclui que “a rede está funcionando”; outro, que “é problema de senha”. Sem método, cada um testa uma coisa: trocam o DNS, reiniciam o serviço, pedem para liberar o firewall. Às vezes acertam por sorte; outras vezes abrem uma porta perigosa e o problema continua.

Os dois podem estar errados, porque o ping testa só um pedaço do caminho. Nesta aula você vai organizar esses pedaços em camadas e saber o que cada teste prova. É o método que suporte, redes, segurança e cloud usam para discutir uma falha com evidências, sem empurrá-la de uma equipe para outra.
