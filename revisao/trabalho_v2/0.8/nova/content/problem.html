Problema

É isso que acontece quando tudo vira “a rede”. Um simples acesso a https://sistema.empresa.local depende de Wi-Fi, endereço IP, caminho até o servidor, DNS, porta, TLS, HTTP, login e permissão. Se todas essas peças são tratadas como uma coisa só, não há como saber qual testar primeiro nem o que um teste que passou realmente prova.

Modelos em camadas existem para dividir essa complexidade em responsabilidades. Por isso equipes e fabricantes diferentes trabalham em partes diferentes: quem fabrica a placa de rede não implementa HTTP, e quem desenvolve a API não lida com o sinal elétrico no cabo. Esta aula mostra quais são essas camadas, como os dados passam por elas e como usá-las para testar cada hipótese no lugar certo.
