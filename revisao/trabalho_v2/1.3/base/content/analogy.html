Analogia

Pense em sistemas de transporte. PAN é levar algo no bolso. LAN é circular dentro de uma casa ou escritório. CAN é circular entre os prédios de uma universidade. MAN é o transporte dentro de uma cidade. WAN são as rodovias entre estados ou países. SAN é um corredor técnico reservado para carga crítica dentro de uma instalação.

Limite da analogia: ela ajuda com o alcance, mas redes não levam objetos inteiros: dividem a informação em unidades e usam protocolos, endereços, filas, retransmissões e políticas.
