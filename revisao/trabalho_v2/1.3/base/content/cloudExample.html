Exemplo em cloud

Em cloud as siglas mudam, mas os conceitos continuam. Uma VPC (AWS, GCP) ou VNet (Azure) é a rede virtual controlada pelo cliente. Subnets organizam segmentos. Peering conecta redes virtuais. VPN e links dedicados ligam a rede corporativa à cloud e fazem o papel de WAN híbrida. Private endpoints dão acesso privado a serviços gerenciados.

Não ver cabo não significa não ter arquitetura de rede: você ainda precisa entender alcance, rota, domínio administrativo, custo de tráfego, inspeção, DNS privado e políticas. Como essa rede é declarada em IaC (subnets, rotas, security groups, endpoints, conexões híbridas), policy as code no pipeline pode impedir que um serviço de produção fique exposto em subnet pública.
