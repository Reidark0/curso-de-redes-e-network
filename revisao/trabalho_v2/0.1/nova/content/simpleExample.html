Exemplo simples

Alguns sites e sistemas antigos usam um tipo simples de login chamado autenticação HTTP Basic. Quando você digita usuário e senha, o navegador passa a enviar, junto com cada pedido ao site, uma linha assim:

Authorization: Basic dXN1YXJpbzpzZW5oYQ==

Lido como texto, dXN1YXJpbzpzZW5oYQ== parece embaralhado. Mas ele está só em Base64, uma codificação que reescreve quaisquer bytes usando letras, números e alguns símbolos. Lido com a regra certa, o mesmo valor é usuario:senha.

Qualquer pessoa que capture essa linha decodifica a senha com um comando, sem chave nenhuma (o laboratório mostra como). Base64 só mudou a forma. Quem protege a senha nesse caso é o TLS, a criptografia da conexão que aparece como https:// no endereço: sem ele, a senha viaja exposta.
