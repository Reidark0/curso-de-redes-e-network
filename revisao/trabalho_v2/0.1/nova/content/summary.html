Resumo

  • Ideia central: rede é uma cadeia de traduções: dado → bytes → bits → sinal → bits → dado. O significado só volta quando o destino usa a regra certa.
  • Informação, dado, byte, bit e sinal são coisas diferentes. 1 byte = 8 bits.
  • Os mesmos bytes mudam de sentido conforme a regra: 01000001 pode ser o número 65 ou a letra A.
  • Bytes ilegíveis não são, por si só, criptografia nem ataque.
  • Base64 e hexadecimal mudam a forma dos dados; não protegem nada.
