Conceito

Definição: representação digital é a conversão de algo significativo para humanos ou aplicações em uma sequência padronizada de bits, que pode ser armazenada, processada, transmitida e reinterpretada por hardware e software.

Um bit é a menor unidade de informação digital: tem dois estados possíveis, normalmente escritos como 0 e 1. Um byte é um grupo de 8 bits. Com esses blocos, computadores representam números, textos, imagens, programas, pacotes de rede, certificados, chaves criptográficas e logs.

Separe três ideias: a informação é o que se quer comunicar; a representação é como essa informação vira bits; a interpretação é o processo de atribuir significado aos bits. A sequência 01000001, por exemplo, pode ser o número 65, a letra A em uma codificação de texto, parte de uma instrução de máquina ou só um byte dentro de um arquivo. Sem contexto, bits são apenas bits.

Em redes, esse contexto vem dos protocolos. O Ethernet define como organizar bytes em um quadro local. O IPv4 define como interpretar campos como versão, tamanho, origem e destino. O TCP define portas, sequência, confirmação e flags. O HTTP define mensagens de aplicação. O TLS define como proteger a comunicação. Cada camada dá significado a bytes que, isolados, não explicam a própria função.

Mudar a representação não é o mesmo que proteger

Quando bytes parecem “estranhos”, eles podem ter passado por transformações muito diferentes:

Transformação Para que serve Como se reverte Exemplo
Codificação Representar dados em outro formato ou alfabeto Qualquer um reverte, sem segredo UTF-8, Base64, hexadecimal
Serialização Transformar uma estrutura (objeto, lista) em sequência de bytes Lendo com o mesmo formato JSON, ASN.1
Compressão Reduzir o tamanho Descompactando, sem segredo gzip
Criptografia Proteger a confidencialidade Só com a chave TLS
Hash Gerar um resumo de tamanho fixo para verificar integridade Não se reverte SHA-256
Erros comuns:
  • Achar que o computador “envia um site”, “uma senha” ou entende texto diretamente. Ele envia sequências de bits; texto é a interpretação de bytes segundo uma codificação, como UTF-8. O significado só aparece porque origem e destino concordam em como interpretar.
  • Confundir dado com sinal físico. Dado é a informação representada; sinal é a forma física que transporta os bits. Misturar os dois faz o diagnóstico confundir problema de aplicação com problema de camada física.
  • Concluir que todo payload ilegível é criptografia ou ataque. Antes, verifique protocolo, formato, compressão, serialização, codificação e contexto.
  • Pular binário e hexadecimal por parecerem teoria demais. Sem eles, subnetting, MAC, IPv6, flags e dumps viram decoreba.
