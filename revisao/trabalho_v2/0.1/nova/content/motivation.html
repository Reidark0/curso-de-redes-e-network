Motivação

Imagine que você trabalha em Segurança da Informação e recebe um alerta do SOC: uma estação interna enviou dados para um servidor externo. A ferramenta mostra endereços IP, portas, protocolo, tamanho do pacote e alguns bytes do payload. Parece só uma tela cheia de números, mas por trás dela existe uma cadeia de transformações: uma intenção humana virou dados de aplicação, os dados viraram bytes, os bytes foram organizados por protocolos em pacotes e quadros, e tudo atravessou um meio físico como cobre, fibra ou rádio.

Computadores não entendem significado humano diretamente: não sabem o que é uma foto, uma senha ou uma requisição HTTP. Eles trabalham com representações construídas a partir de estados físicos que conseguem distinguir. Quando você estudar endereço MAC, IPv4, subnetting, flags TCP, TLS, Base64, payloads e logs, estará respondendo variações da mesma pergunta: como essa informação foi representada para ser armazenada, transmitida e interpretada?
