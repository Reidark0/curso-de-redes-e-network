História

Os primeiros sistemas comerciais precisavam representar texto em inglês: letras, dígitos, pontuação e alguns caracteres de controle. O ASCII resolveu isso com uma tabela de 7 bits (128 valores, de 0 a 127) que associa números a caracteres. A letra A, por exemplo, é o decimal 65, o hexadecimal 0x41 e o binário 0100 0001.

Acentos, outros alfabetos, símbolos e ideogramas não cabem em 128 valores. Surgiram então tabelas locais de 8 bits (como ISO-8859-1, também chamada Latin-1, e Windows-1252) que usam os valores de 128 a 255 para caracteres regionais. Isso criou fragmentação: o mesmo byte significa caracteres diferentes conforme a tabela usada. É daí que vem o texto quebrado, como UsuÃ¡rio no lugar de Usuário.

O Unicode organizou um repertório universal, atribuindo a cada caractere um ponto de código, como U+0041 para A e U+00E1 para á. Ponto de código ainda não é a sequência de bytes transmitida: para isso existem codificações como UTF-8, UTF-16 e UTF-32. O UTF-8 dominou a web e os sistemas modernos porque os caracteres ASCII continuam ocupando 1 byte, com os mesmos valores, e os demais usam de 2 a 4 bytes.
