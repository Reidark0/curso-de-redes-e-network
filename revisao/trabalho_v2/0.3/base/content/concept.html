Conceito

Um caractere é a unidade textual que você percebe, como A, ç, ? ou €. Um ponto de código é o número atribuído a esse caractere no Unicode. Uma codificação (encoding) é a regra que transforma pontos de código em bytes. Charset, na prática, indica qual codificação usar para interpretar o texto (por exemplo, charset=utf-8 num cabeçalho HTTP), embora o uso histórico do termo varie.

Definição essencial: ASCII é uma tabela histórica de caracteres básicos; Unicode é um padrão amplo que atribui números a caracteres; UTF-8 é uma codificação que transforma pontos de código Unicode em bytes; Base64 é uma forma de representar bytes quaisquer usando caracteres de texto seguros.

Para redes, o ponto central é: a rede transporta bytes, e o significado deles depende do protocolo e da codificação combinada. Quando uma API diz que envia JSON em UTF-8, o corpo é texto JSON cujos bytes devem ser lidos como UTF-8. Quando um certificado está em PEM, os bytes binários do certificado foram codificados em Base64 para caber num arquivo de texto.
