Problema

É isso que acontece quando texto vira bytes por uma regra e é lido por outra, ou quando bytes precisam passar por um canal que só aceita texto. Nos dois casos a rede entregou os bytes intactos; o que falhou foi a regra.

As regras de texto se multiplicaram porque a primeira, o ASCII, só cobria o inglês. Cada região criou então a sua tabela, e o mesmo byte passou a significar letras diferentes conforme quem lia. O Unicode e o UTF-8 resolveram isso, mas sistemas antigos e configurações erradas continuam misturando regras.

Já o e-mail e formatos como o JSON foram feitos para carregar texto, e um arquivo (uma foto, um PDF) é feito de bytes quaisquer. Para levá-lo por esses canais, os bytes são reescritos como texto em Base64, e isso tem um custo de tamanho. Esta aula mostra as duas regras por dentro.
