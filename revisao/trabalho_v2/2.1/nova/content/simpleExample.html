Exemplo simples

Você abre um site no notebook e a página não carrega. Para ela aparecer, uma cadeia de condições precisa funcionar:

  1. Camada 1: o cabo está conectado ou o Wi-Fi tem sinal.
  2. Camada 2: o notebook consegue entregar dados ao roteador da rede local.
  3. Camada 3: o IP do servidor é alcançável, passando pelo gateway.
  4. Camada 4: a conexão com a porta 443 do servidor abre.
  5. Camadas 5 a 7: o TLS negocia a criptografia, o HTTP envia o pedido e o servidor responde.

Se a página não abre, a pergunta é: em qual dessas etapas a evidência quebra? Um caso típico: o ping ao IP do servidor responde, mas o site não abre pelo nome. As camadas 1 a 3 funcionam até o servidor. O DNS, que transforma o nome do site em IP, é um serviço da camada 7, então a suspeita vai para ele, não para o cabo.
